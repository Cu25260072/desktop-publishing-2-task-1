# desktop-publishing-2-task-1
New File: Ctrl + N → Set 1200 × 800 px, White background → Create.
Red Rectangle: Select Rectangle Tool (U) → Set Fill Red, Stroke Black (1px) → Drag on top-left.  
Blue Circle: Select Ellipse Tool (U) → Set Fill Blue, Stroke Black (1px) → Hold Shift and drag on top-right.   
Green Star: Select Polygon Tool (U) → Set Sides: 5, Indent/Star: 50%, Fill Green, Stroke Black (1px) → Hold Shift and drag at bottom-center.
Add Text: Select Type Tool (T) → Type Name, Roll No, and Course → Align with Move Tool (V).Save & Export: Ctrl + S to save as PSD → Ctrl + Shift + Alt + S (or Export As) to save as JPEG/PNG.
